MediaData Player

Universal Media Player for Android

Professional video and audio playback with Google Cast support

📱 View on GitHub ⬇️ Save file Media APK

✨ Key Features

🎥

Video Playback

Professional video player powered by Media3 (ExoPlayer) with hardware acceleration, subtitle support, and gesture controls.

🎵

Audio Player

Beautiful audio player with Spotify-style interface, background playback, and audio queue management.

📡

Network Streaming

Stream content from direct URLs with support for DASH, HLS, and RTSP protocols.

📺

Google Cast

Cast videos and audio to your TV or Chromecast devices with full playback controls.

💾

Save file Media Manager

Save file Media network media to local storage with progress notifications and resume capability.

🌍

Multi-Language

Full support for 13 languages including English, Vietnamese, Spanish, French, German, and more.

🎨

Material Design 3

Modern UI built with Jetpack Compose following Google's latest Material Design guidelines.

⚙️

Customizable

Adjust subtitle size, color, position, playback speed, and more to your preferences.

📁

File Management

Browse and manage your local media files with delete, rename, and organize features.

🎬 Supported Formats

DASH
HLS (m3u8)

RTSP
HTTP(S) URLs
